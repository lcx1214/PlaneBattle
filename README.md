# 飞机大战（局域网联机） · Plane Battle

一个严格按照《参数化纸面空战》规格实现的局域网双人对战游戏，使用 **Python 3 + tkinter + socket**，
**无任何第三方依赖**，兼容 **Windows 7 及以上**（建议 Python 3.8，因其为最后一个官方支持 Win7 的版本；
在 Win10/11 上使用 Python 3.9+ 亦可）。

- 界面语言：**中文**，并支持 **English / 日本語** 一键切换
- 操作：**纯鼠标** 或 **纯键盘** 均可
- 显示：**完整地图**（带坐标刻度、可滚动）、图例、朝向预览、战斗日志
- 模式：**局域网双人对战** 与 **人机对战（单人）** 两种
- 平台：**Windows exe** 与 **Android APK**（可跨平台局域网联机）

---

## 打包产物

- **Windows 可执行文件**：`dist/飞机大战.exe`（单文件、免装 Python、无控制台窗口）。
- **Android 移动端**：`mobile/` 目录为 Kivy 触摸版源码，APK 打包方法见 `mobile/README.md`（支持 GitHub Actions 云端打包）。
- 两者共用同一套 TCP 联机协议，**可在同一局域网内互相对战**。

## 一、运行要求

1. 安装 Python 3.7+（Windows 7 请使用 **3.8.x**，安装时勾选 *Add python.exe to PATH*）。
   - 下载：https://www.python.org/downloads/
2. 无需 `pip install` 任何东西 —— 只用标准库（tkinter / socket / json / threading）。

## 二、启动方式

- 双击 `启动游戏.bat`（使用 `pythonw` 启动，**不显示黑色控制台窗口**）。
- 需要查看报错时，可在该目录执行 `python main.py`；用 `pythonw` 启动时异常会写入 `error.log`。

## 三、局域网对战流程

> 两台电脑需处于**同一局域网**（同一路由器/交换机下），或使用热点组网。
> 首次运行请允许 Windows 防火墙放行 Python（专用网络）。

1. **主机**：点击「创建房间（主机）」，填写**端口**（默认 34567，双方需一致），点「开始等待连接」，记下屏幕显示的 **IP 地址与端口**。
2. **客户端**：点击「加入房间（客户端）」，填入主机 **地址（IP 或域名，内网穿透可填域名）** 与端口，点「连接」。
3. **约定参数**：主机设定 `棋盘宽 X`、`棋盘高 Y`、`飞机数量`（均 ≥ 合理下限），发送给客户端确认。
4. **部署**：双方在自己的棋盘上放置全部飞机（可旋转 4 种朝向；支持随机布置），完成后点「完成部署」。
5. **对战**：轮流攻击对方棋盘坐标，先击落对方全部飞机**机头**者获胜。
6. 结束后可「再来一局」或「返回主菜单」。

### 单机自测（同一台电脑开两个窗口）
- 窗口 A 创建房间；窗口 B 加入房间，IP 填 `127.0.0.1`。

## 三-1、人机对战（单人）

- 主菜单点击「人机对战（单人）」，设定参数即可开始，无需联网。
- 你为主机（玩家1），先手随机；AI 采用「命中后追打相邻格」的猎杀策略。

## 四、规则摘要

### 参数
| 参数 | 含义 |
| --- | --- |
| `MAP_WIDTH` | 棋盘横向列数（X），≥ 5 |
| `MAP_HEIGHT` | 棋盘纵向行数（Y），≥ 5 |
| `NUM_PLANES` | 每名玩家飞机数，≥ 1，且 `NUM_PLANES × 10 ≤ MAP_WIDTH × MAP_HEIGHT` |

### 飞机形状（“士”字形，10 格）
机头 1 格 + 主翼 5 格 + 机身 1 格 + 尾翼 3 格，边界框 **宽 5 × 高 4**。
4 种朝向（上/右/下/左）为顺时针旋转：
- 0°：`(ΔX, ΔY)`
- 90°：`(-ΔY, ΔX)`
- 180°：`(-ΔX, -ΔY)`
- 270°：`(ΔY, -ΔX)`

### 攻击判定优先级（从高到低）
| 优先级 | 条件 | 返回 | 效果 |
| --- | --- | --- | --- |
| 1 | 越界 或 本局已攻击过该坐标 | `INVALID` | 无变更，回合作废，需重选 |
| 2 | 命中存活飞机的**机头** | `DESTROYED` | 整机坠毁，其余未损格转为残骸 |
| 3 | 命中存活飞机的机翼/机身/尾翼 | `DAMAGED` | 该格受损，飞机仍存活 |
| 4 | 命中已坠毁飞机的任意部件 | `WRECKAGE` | 无变更 |
| 5 | 从未属于任何飞机 | `EMPTY` | 无变更 |

### 胜负
每次攻击结算后，若防守方**所有机头均被击中**（全部坠毁），攻击方**立即获胜**。

## 五、操作说明

### 鼠标
- **部署**：点击空格放置机头；点击已放飞机可移除；按钮切换朝向/随机/清空/完成。
- **战斗**：点击敌方棋盘格子进行攻击（己方回合时）。

### 键盘
- **方向键**：移动光标
- **R**：旋转朝向（部署阶段）
- **回车 / 空格**：放置（部署）/ 攻击（战斗）
- **Delete / BackSpace**：移除光标下的飞机（部署）

## 七、常见问题

- **连接不上**：检查是否同一局域网、IP/端口是否正确、防火墙是否放行 Python。
- **端口被占用**：主机在创建房间时换一个端口（需双方一致）。
- **窗口内棋盘太大**：棋盘带滚动条；或把地图参数设小一些。
- **自动布置失败**：参数校验会提前拒绝“放不下”的配置（如 10×10 放 10 架）；若仍遇随机布置失败，请手动放置。
